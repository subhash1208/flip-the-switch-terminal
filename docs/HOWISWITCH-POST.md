## LinkedIn (long version)

"Works on my machine" — the four most expensive words in software.

We built ParityCourt for the Flip the Switch hackathon. It turns the back-and-forth debugging ping-pong into a courtroom:

🔹 Claude Code on Alice's Mac fingerprints her working environment
🔹 A Bob agent on the failing Linux box does the same
🔹 A custom Python Bailiff agent compares the two, redacts secrets, and runs one ablation to isolate the root cause
🔹 Each machine owner approves only their own probes — enforced by Switch, not by message text

The verdict? A replay-able receipt anyone can re-run. The fix is verified where it failed, not where it works.

Three agents. Two real machines. One Switch room. Delete Switch, and these agents can't see each other's machines.
